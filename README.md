# 📌 서비스 소개

## ✨ 개요
일정마다 **스트레스 강도(1~5)** 를 태깅하여  
일·주·월 단위 누적 스트레스를 계산하고,  
과부하 시 즉시 경고하며 AI가 적합한 시간대를 추천합니다.

### 주요 기능
- 스트레스 기반 일정 충돌/과부하 검증  
- 스트레스 총량 자동 계산  
- FullCalendar 일정 UI  
- AI 일정 재배치 추천  
- SSE 기반 실시간 알림(Toast)

---

# 🌿 타 서비스 대비 차별점

## 1) 스트레스 기반 일정 관리
- 스트레스 태깅 (1~5)  
- ‘통제 불가’ 일정 구분  
- 하루 최대 스트레스 한도 설정  
- 초과 시 일정 등록 제한 (408)  
- 스트레스 레벨별 색상 적용

## 2) AI 스마트 스케줄링
- 부담 집중일 자동 분석  
- 일정 분산 제안  
- 일정 사이 휴식 버퍼 자동 삽입  
- `/ai/rearrangement/{schedule_id}` → AI가 새로운 시간대 추천

## 3) 실시간 알림(SSE)

### 🔮 AI 일정 추천
- 일정 충돌, 과부하, 스트레스 초과 등이 감지되면  
  AI가 즉시 **대체 일정 추천** 또는 **일정 재배치 솔루션**을 실시간으로 전달합니다.


### 🔔 토스트 팝업 표시
- SSE로 전달된 메시지를 수신하면  
  React의 Toast 컴포넌트가 자동으로 팝업을 띄웁니다.
- 사용자는 별도의 조작 없이 **즉각적인 실시간 알림 경험**을 얻을 수 있습니다.


# 🛠 구현 내용

## 일정 기능
- 등록 / 수정 / 삭제  
- 충돌 검증: 200 OK / 406 중복 / 408 과부하  
- 스트레스 합계 조회: `/stress/summary`

- 토스트 팝업

## 마이페이지

- 일정 과부하 기준으로 활용

- Google OAuth2  
- 신규 유저 정보 등록 후 자동 로그인
